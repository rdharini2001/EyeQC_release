# Research figures generated from uploaded photographs

`real-spatial-maps.png`: authentic EyeQC local-readability outputs from six user-provided retinal photographs. The 6×6 spatial score is interpolated for visualization, and colour values reflect interpretable local measurement, not GT segmentation or DINO attribution.

`real-degradations.png`: photographs altered with the exact provided `apply_degradation` routine, with the known manipulated region and computed local map. This is a qualitative illustration, not independent evidence of localization accuracy.

Check the source images' redistribution rights before committing these figures to a public repository or clinical website.
